# How Boston counts bikes

## Count day
term: count_day

Each location is counted for about two days, a few times a year, so small samples move a lot. Report the number of count days alongside any average.

## Comparing seasons
term: season

Since 2020 the City also counts in winter and spring, which lowers all-season averages. Compare the same season across years.
