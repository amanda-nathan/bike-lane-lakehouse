# NYC protected lanes, before and after

## Near a new lane
term: near_new_lane

A crash counts as near a new protected lane if it happened within about 50 meters (half a block) of the lane segment. We compare the 2 years before the lane went in with the 2 years after.

## Which lanes count as new
term: new_lane

Only segments that got their first protected lane between January 2015 and October 2024 count, so both windows fall inside the crash data, which starts in July 2012.
